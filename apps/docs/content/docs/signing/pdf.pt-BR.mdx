**O que você vai fazer:** assinar bytes de PDF em PAdES com `signPdf`, escolher a política `"pades-ades"` ou `"pades-icp-brasil"` (AD-RB), adicionar carimbos visíveis opcionais e verificar o resultado com `verifyPdf`.

A camada `Signatures`, fornecida pelo `a1SignaturesLayer`, faz a assinatura; o módulo de PDF apenas modifica o documento.

## Instale o pacote

O módulo de PDF é `@signature-kit/pdf`. Ele consome a mesma camada fornecida pelo signatário A1.

```package-install
@signature-kit/pdf
```

<Callout type="info">
  `signPdf` exige o serviço `Signatures` no canal de requisitos; `verifyPdf` não.
</Callout>

## Assine um PDF

`signPdf(input: PdfSigningRequest)` retorna um `Effect<Uint8Array, PdfError | CmsError | SignatureKitError, Signatures>` — os bytes do PDF assinado. Forneça `Signatures` com `Effect.provide(a1SignaturesLayer(...))`.

```ts title="sign-pdf.ts"
import { signPdf } from "@signature-kit/pdf/sign"
import { a1SignaturesLayer } from "@signature-kit/a1/signer"
import { Effect, Redacted } from "effect"

const signedPdf = await Effect.runPromise(
  signPdf({
    pdf,
    name: "Maria Souza",
    reason: "Assinado para aprovação",
    location: "São Paulo, BR",
    policy: "pades-icp-brasil",
    signatureLength: 32768,
  }).pipe(
    Effect.provide(
      a1SignaturesLayer({
        pfx,
        password: Redacted.make(password),
      }),
    ),
  ),
)
```

`signatureLength` reserva o placeholder de `/Contents`. Se a assinatura CMS for maior que o placeholder, a assinatura falha com `pdf.SIGNATURE_TOO_LARGE`; aumente o placeholder e assine novamente.

## Política ICP-Brasil AD-RB

`policy: "pades-icp-brasil"` usa os metadados fixos da PA_PAdES_AD_RB_v1_1 em `@signature-kit/cms/icp-brasil`. Só sobrescreva os metadados da política quando você possuir esses fatos.

```ts title="politica-explicita.ts"
const signedPdf = signPdf({
  pdf,
  policy: {
    oid: "2.16.76.1.7.1.11.1.1",
    hashBase64: policyHashBase64,
    hashAlgorithm: "sha256",
  },
})
```

<Callout type="warn" title="AD-RB proíbe signingTime no CMS">
  Com `policy: "pades-icp-brasil"`, o atributo assinado CMS `signingTime` é proibido. O SignatureKit o mantém fora do CMS para AD-RB; um `timestamp` opcional alimenta apenas o campo `M` do dicionário de assinatura PDF. O validador oficial do ITI rejeita assinaturas CMS com `signingTime` nessa política.
</Callout>

## Carimbos visíveis

Carimbos visíveis são desenhados antes da assinatura criptográfica ser embutida, então os bytes da página carimbada ficam cobertos pela assinatura. Passe `stamp` para um bloco visível completo e `rubric` quando precisar de rubricas/iniciais em outras páginas.

```ts title="carimbo-visivel.ts"
const signedPdf = signPdf({
  pdf,
  policy: "pades-icp-brasil",
  stamp: {
    pageIndex: 0,
    rect: [72, 72, 260, 124],
    badge: {
      header: { text: "ASSINADO DIGITALMENTE" },
      rows: [
        [{ label: "Signatário", value: "Maria Souza" }],
        [{ label: "CPF", value: "***.123.456-**" }],
      ],
      footer: [
        { text: "ICP-Brasil" },
        { text: "Validar no ITI", link: "https://validar.iti.gov.br/" },
      ],
      qr: { text: "https://validar.iti.gov.br/" },
      theme: {
        borderColor: "#1D4ED8",
        backgroundColor: "#FFFFFF",
        headerBackgroundColor: "#DBEAFE",
        qrColor: "#1E3A8A",
      },
    },
  },
})
```

O schema de `badge` suporta:

- `header.text` para o rótulo superior;
- `rows` como uma ou mais linhas de células `{ label?, value }`;
- segmentos em `footer` com `link` opcional; links viram anotações PDF;
- `qr.text` para um QR code gerado e renderizado no badge;
- `theme` com cores hexadecimais de borda, fundo, cabeçalho, texto, separador, QR e rodapé.

Use `inkPng` quando você já tem uma imagem PNG de assinatura manuscrita. Use `lines` para texto simples, ou `badge` para o carimbo estruturado em estilo governamental. Um carimbo visível exige exatamente um de `lines`, `badge`, `inkPng` ou `qr`.

```ts title="rubrica-e-imagem.ts"
const signedPdf = signPdf({
  pdf,
  stamp: {
    pageIndex: 0,
    rect: [72, 72, 220, 118],
    inkPng: signatureImagePng,
  },
  rubric: {
    rect: [500, 36, 560, 72],
    pages: "all-except-signature",
    initials: "MS",
    initialsTheme: {
      inkColor: "#111827",
      bracketColor: "#2563EB",
      backgroundColor: "#EFF6FF",
    },
  },
})
```

`pages: "all-except-signature"` é o padrão seguro de rubrica: a página principal recebe o bloco visível completo; as outras páginas recebem iniciais. Documentos de uma página pulam a rubrica.

Para posicionamento por âncora — encontrar texto como "Assinatura" e transformá-lo em retângulo — use a [receita de posicionamento por âncora](/docs/recipes/anchor-placement).

## Verifique um PDF

`verifyPdf` checa ByteRange, assinatura CMS e cobertura. Ele retorna um valor, então assinaturas inválidas aparecem como `valid: false`.

```ts title="verify-pdf.ts"
import { verifyPdf } from "@signature-kit/pdf/verify"

const report = await Effect.runPromise(verifyPdf({ pdf: signedPdf }))

report.valid
report.signatures.length
```

Se você também precisa validar o perfil AD-RB, rode `validatePdfConformance` de `@signature-kit/iti/conformance` depois da assinatura.
