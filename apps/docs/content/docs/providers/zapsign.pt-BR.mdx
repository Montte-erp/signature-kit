**O que você vai fazer:** criar um request remoto de assinatura ZapSign, manter credenciais Redacted e usar apenas os helpers de lifecycle exportados por `@signature-kit/zapsign`.

ZapSign faz upload de um único PDF, cria a lista de signatários e devolve a primeira URL de assinatura quando disponível. O schema local força o shape de um único PDF `application/pdf`.

## Instalação

```package-install
@signature-kit/http @signature-kit/zapsign
```

## Quando usar

Use ZapSign quando o produto quer um link hospedado de assinatura após upload simples de PDF. Use A1/PDF local quando não há cerimônia upstream.

<Callout type="error" title="Mantenha credenciais Redacted">
  Tokens de provedor entram como `Redacted.make(...)` e são abertos apenas dentro da fronteira HTTP do pacote. Nunca passe tokens remotos para componentes React ou logs.
</Callout>

## Request mínimo

```ts title="zapsign.ts"
import * as Alchemy from "alchemy"
import { ZapSignSignatureRequest, providers as zapSignProviders } from "@signature-kit/zapsign"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Effect, Layer, Redacted } from "effect"

export default class Contracts extends Alchemy.Stack<Contracts>()(
  "Contracts",
  {
    providers: zapSignProviders({
        apiToken: Redacted.make(process.env.ZAPSIGN_API_TOKEN ?? ""),
        environment: "sandbox",
      }).pipe(
        // effect-boundary: Alchemy StackProps.providers closes provider and transport layers. [allow-provide]
        Layer.provide(signatureHttpClientLive),
        Layer.orDie,
      ),
    state: Alchemy.inMemoryState(),
  },
  Effect.gen(function* () {
    return yield* ZapSignSignatureRequest("contract", {
      title: "Contrato de prestação de serviço",
      message: "Assine este contrato.",
      documents: [
        { fileName: "contract.pdf", mimeType: "application/pdf", contentBase64: pdfBase64 },
      ],
      recipients: [{ name: "Maria Souza", email: "maria@example.com", routingOrder: 1 }],
      send: false,
    })
  }),
) {}
```

## Lifecycle

| Função | Suportada | Notas |
| --- | --- | --- |
| `ZapSignSignatureRequest(id, props)` | Sim | Recurso Alchemy retido. `reconcile` cria uma vez e devolve o output em cache nos planos seguintes. |
| `getZapSignSignatureRequest(options, id)` | Sim | Lê o estado do request upstream. |
| `listZapSignSignatureRequests(options)` | Sim | Endpoint upstream de listagem no pacote; o `list` do provider Alchemy devolve `[]` e `nuke` é pulado. |
| `cancelZapSignSignatureRequest(options, id)` | Sim | Usa o endpoint de cancelamento do provedor para requests remotos canceláveis. |
| `deleteZapSignSignatureRequest(options, id)` | Sim | Deleta o request upstream quando o provedor suporta deleção. Remoto ausente é sucesso. |
| `downloadZapSignSignedDocument(options, id)` | Sim | Só funciona quando a ZapSign expõe `signed_file`; antes disso falha como `signature-kit.UNSUPPORTED_OPERATION`. |

A criação é um POST de documento único; não há sequência de rollback multi-etapa para compensar após workflow parcial do provedor. Planos seguintes reutilizam o output em cache.

## Erros

Input inválido, falhas HTTP remotas e shapes de resposta inválidos falham como `SignatureKitError`. Os campos `provider`, `operation` e `status` HTTP são preservados quando a resposta upstream expõe esses dados.
