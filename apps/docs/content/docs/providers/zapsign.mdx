**What you'll do:** create a ZapSign remote-signature request, keep credentials Redacted, and use only the lifecycle helpers exported by `@signature-kit/zapsign`.

ZapSign uploads a single PDF, creates a signer list, and returns the first signing URL when available. The local schema enforces the single-PDF `application/pdf` input shape.

## Installation

```package-install
@signature-kit/http @signature-kit/zapsign
```

## When to use

Use ZapSign when the product wants a hosted signing link after a simple PDF upload. Use local A1/PDF signing when no upstream ceremony is involved.

<Callout type="error" title="Keep credentials Redacted">
  Provider tokens enter as `Redacted.make(...)` and are unwrapped only inside the package HTTP boundary. Never pass remote tokens to React components or logs.
</Callout>

## Minimal request

```ts title="zapsign.ts"
import * as Alchemy from "alchemy"
import { ZapSignSignatureRequest, providers as zapSignProviders } from "@signature-kit/zapsign"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Effect, Layer, Redacted } from "effect"

export default class Contracts extends Alchemy.Stack<Contracts>()(
  "Contracts",
  {
    providers: zapSignProviders({
        apiToken: Redacted.make(process.env.ZAPSIGN_API_TOKEN ?? ""),
        environment: "sandbox",
      }).pipe(
        // effect-boundary: Alchemy StackProps.providers closes provider and transport layers. [allow-provide]
        Layer.provide(signatureHttpClientLive),
        Layer.orDie,
      ),
    state: Alchemy.inMemoryState(),
  },
  Effect.gen(function* () {
    return yield* ZapSignSignatureRequest("contract", {
      title: "Service agreement",
      message: "Please sign this agreement.",
      documents: [
        { fileName: "contract.pdf", mimeType: "application/pdf", contentBase64: pdfBase64 },
      ],
      recipients: [{ name: "Maria Souza", email: "maria@example.com", routingOrder: 1 }],
      send: false,
    })
  }),
) {}
```

## Lifecycle

| Function | Supported | Notes |
| --- | --- | --- |
| `ZapSignSignatureRequest(id, props)` | Yes | Retained Alchemy resource. `reconcile` creates once and returns cached output on later plans. |
| `getZapSignSignatureRequest(options, id)` | Yes | Reads the upstream request state. |
| `listZapSignSignatureRequests(options)` | Yes | Package-level upstream list endpoint; Alchemy provider `list` returns `[]` and `nuke` is skipped. |
| `cancelZapSignSignatureRequest(options, id)` | Yes | Uses the provider cancel endpoint for cancellable remote requests. |
| `deleteZapSignSignatureRequest(options, id)` | Yes | Deletes the upstream request when the provider supports deletion. A missing remote is success. |
| `downloadZapSignSignedDocument(options, id)` | Yes | Only succeeds when ZapSign exposes `signed_file`; before that it fails as `signature-kit.UNSUPPORTED_OPERATION`. |

Create is a single-document POST; no multi-step rollback sequence is needed to compensate after a partial provider workflow. Subsequent plans reuse cached output.

## Errors

Invalid input, remote HTTP failures, and invalid response shapes fail as `SignatureKitError`. The `provider`, `operation`, and HTTP `status` fields are preserved when the upstream response exposes them.
