**What you'll do:** create a Documenso remote-signature request, keep credentials Redacted, and use only the lifecycle helpers exported by `@signature-kit/documenso`.

Documenso creates a v2 envelope, uploads PDFs as multipart files, and can distribute the envelope when `send` is enabled.

## Installation

```package-install
@signature-kit/http @signature-kit/documenso
```

## When to use

Use Documenso when envelope ownership, routing, and recipient actions live in Documenso. Use local signing for in-process PDF/PAdES bytes.

<Callout type="error" title="Keep credentials Redacted">
  Provider tokens enter as `Redacted.make(...)` and are unwrapped only inside the package HTTP boundary. Never pass remote tokens to React components or logs.
</Callout>

## Minimal request

```ts title="documenso.ts"
import * as Alchemy from "alchemy"
import { DocumensoSignatureRequest, providers as documensoProviders } from "@signature-kit/documenso"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Effect, Layer, Redacted } from "effect"

export default class Contracts extends Alchemy.Stack<Contracts>()(
  "Contracts",
  {
    providers: documensoProviders({
        apiKey: Redacted.make(process.env.DOCUMENSO_API_KEY ?? ""),
        authorizationScheme: "bearer",
      }).pipe(
        // effect-boundary: Alchemy StackProps.providers closes provider and transport layers. [allow-provide]
        Layer.provide(signatureHttpClientLive),
        Layer.orDie,
      ),
    state: Alchemy.inMemoryState(),
  },
  Effect.gen(function* () {
    return yield* DocumensoSignatureRequest("contract", {
      title: "Service agreement",
      message: "Please sign this agreement.",
      documents: [
        { fileName: "contract.pdf", mimeType: "application/pdf", contentBase64: pdfBase64 },
      ],
      recipients: [{ name: "Maria Souza", email: "maria@example.com", role: "signer", routingOrder: 1 }],
      send: false,
    })
  }),
) {}
```

## Lifecycle

| Function | Supported | Notes |
| --- | --- | --- |
| `DocumensoSignatureRequest(id, props)` | Yes | Retained Alchemy resource. `reconcile` creates once and returns cached output on later plans. |
| `getDocumensoSignatureRequest(options, id)` | Yes | Reads the upstream request state. |
| `listDocumensoSignatureRequests(options)` | Yes | Package-level upstream list endpoint; Alchemy provider `list` returns `[]` and `nuke` is skipped. |
| `cancelDocumensoSignatureRequest(options, id)` | Yes | Uses the provider cancel endpoint for cancellable remote requests. |
| `deleteDocumensoSignatureRequest(options, id)` | Yes | Deletes the upstream request when the provider supports deletion. A missing remote is success. |
| `downloadDocumensoSignedDocument(options, id)` | Yes | Only succeeds after the envelope is completed and an envelope item id is available; otherwise it fails as `signature-kit.UNSUPPORTED_OPERATION`. |

Multi-step create rollback deletes remote state only after unambiguous pre-effect 4xx failures, excluding 408, 409, 429, 5xx, timeouts, and response-shape failures.

## Errors

Invalid input, remote HTTP failures, and invalid response shapes fail as `SignatureKitError`. The `provider`, `operation`, and HTTP `status` fields are preserved when the upstream response exposes them.
