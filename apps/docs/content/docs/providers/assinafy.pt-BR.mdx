title: Assinafy
description: "Crie requests de documento Assinafy com credenciais por conta e erros tipados do SignatureKit."
---

**O que você vai fazer:** criar um request remoto de assinatura Assinafy, manter credenciais Redacted e usar apenas os helpers de lifecycle exportados por `@signature-kit/assinafy`.

Assinafy cria o documento, registra o signatário e cria o assignment na conta configurada. O SignatureKit mantém o shape tipado e deixa a cerimônia com a Assinafy.

## Instalação

```package-install
@signature-kit/http @signature-kit/assinafy
```

## Quando usar

Use Assinafy quando organização por conta e tracking de assignment pertencem à Assinafy. Use assinatura local quando sua app possui os bytes assinados e o posicionamento.

<Callout type="error" title="Mantenha credenciais Redacted">
  Tokens de provedor entram como `Redacted.make(...)` e são abertos apenas dentro da fronteira HTTP do pacote. Nunca passe tokens remotos para componentes React ou logs.
</Callout>

## Request mínimo

```ts title="assinafy.ts"
import * as Alchemy from "alchemy"
import { AssinafySignatureRequest, providers as assinafyProviders } from "@signature-kit/assinafy"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Effect, Layer, Redacted } from "effect"

export default class Contracts extends Alchemy.Stack<Contracts>()(
  "Contracts",
  {
    providers: assinafyProviders({
        accountId: process.env.ASSINAFY_ACCOUNT_ID ?? "",
        apiKey: Redacted.make(process.env.ASSINAFY_API_KEY ?? ""),
        environment: "sandbox",
      }).pipe(
        // effect-boundary: Alchemy StackProps.providers closes provider and transport layers. [allow-provide]
        Layer.provide(signatureHttpClientLive),
        Layer.orDie,
      ),
    state: Alchemy.inMemoryState(),
  },
  Effect.gen(function* () {
    return yield* AssinafySignatureRequest("contract", {
      title: "Contrato de prestação de serviço",
      message: "Assine este contrato.",
      documents: [
        { fileName: "contract.pdf", mimeType: "application/pdf", contentBase64: pdfBase64 },
      ],
      recipients: [{ name: "Maria Souza", email: "maria@example.com", routingOrder: 1 }],
      send: false,
    })
  }),
) {}
```

## Lifecycle

| Função | Suportada | Notas |
| --- | --- | --- |
| `AssinafySignatureRequest(id, props)` | Sim | Recurso Alchemy retido. `reconcile` cria uma vez e devolve o output em cache nos planos seguintes. |
| `getAssinafySignatureRequest(options, id)` | Sim | Lê o estado do request upstream. |
| `listAssinafySignatureRequests(options)` | Sim | Endpoint upstream de listagem no pacote; o `list` do provider Alchemy devolve `[]` e `nuke` é pulado. |
| Helper de cancelamento | Não exportado | Este pacote de provedor não expõe helper público de cancelamento. Use delete apenas quando o upstream suporta remover o request remoto. |
| `deleteAssinafySignatureRequest(options, id)` | Sim | Deleta o request upstream quando o provedor suporta deleção. Remoto ausente é sucesso. |
| `downloadAssinafySignedDocument(options, id)` | Sim | Só funciona depois que a Assinafy expõe um artefato de download concluído; antes disso falha como `signature-kit.UNSUPPORTED_OPERATION`. |

Rollback de criação multi-etapa só deleta estado remoto depois de falhas 4xx inequívocas antes do efeito externo final, excluindo 408, 409, 429, 5xx, timeouts e falhas de shape de resposta.

## Erros

Input inválido, falhas HTTP remotas e shapes de resposta inválidos falham como `SignatureKitError`. Os campos `provider`, `operation` e `status` HTTP são preservados quando a resposta upstream expõe esses dados.
