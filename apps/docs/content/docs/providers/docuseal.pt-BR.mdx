**O que você vai fazer:** criar um request remoto de assinatura DocuSeal, manter credenciais Redacted e usar apenas os helpers de lifecycle exportados por `@signature-kit/docuseal`.

DocuSeal cria uma submissão PDF e devolve links de submitter. É uma API de request de provedor, não uma layer local de signer.

## Instalação

```package-install
@signature-kit/http @signature-kit/docuseal
```

## Quando usar

Use DocuSeal quando um signatário remoto open-source deve hospedar a submissão e coletar assinaturas. Use assinatura local quando o SignatureKit deve produzir os bytes finais.

<Callout type="error" title="Mantenha credenciais Redacted">
  Tokens de provedor entram como `Redacted.make(...)` e são abertos apenas dentro da fronteira HTTP do pacote. Nunca passe tokens remotos para componentes React ou logs.
</Callout>

## Request mínimo

```ts title="docuseal.ts"
import * as Alchemy from "alchemy"
import { DocuSealSignatureRequest, providers as docuSealProviders } from "@signature-kit/docuseal"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Effect, Layer, Redacted } from "effect"

export default class Contracts extends Alchemy.Stack<Contracts>()(
  "Contracts",
  {
    providers: docuSealProviders({
        apiKey: Redacted.make(process.env.DOCUSEAL_API_KEY ?? ""),
        submittersOrder: "preserved",
      }).pipe(
        // effect-boundary: Alchemy StackProps.providers closes provider and transport layers. [allow-provide]
        Layer.provide(signatureHttpClientLive),
        Layer.orDie,
      ),
    state: Alchemy.inMemoryState(),
  },
  Effect.gen(function* () {
    return yield* DocuSealSignatureRequest("contract", {
      title: "Contrato de prestação de serviço",
      subject: "Assine",
      message: "Assine este contrato.",
      documents: [
        { fileName: "contract.pdf", mimeType: "application/pdf", contentBase64: pdfBase64 },
      ],
      recipients: [{ name: "Maria Souza", email: "maria@example.com", role: "signer" }],
      send: false,
    })
  }),
) {}
```

## Lifecycle

| Função | Suportada | Notas |
| --- | --- | --- |
| `DocuSealSignatureRequest(id, props)` | Sim | Recurso Alchemy retido. `reconcile` cria uma vez e devolve o output em cache nos planos seguintes. |
| `getDocuSealSignatureRequest(options, id)` | Sim | Lê o estado do request upstream. |
| `listDocuSealSignatureRequests(options)` | Sim | Endpoint upstream de listagem no pacote; o `list` do provider Alchemy devolve `[]` e `nuke` é pulado. |
| Helper de cancelamento | Não exportado | Este pacote de provedor não expõe helper público de cancelamento. Use delete apenas quando o upstream suporta remover o request remoto. |
| `deleteDocuSealSignatureRequest(options, id)` | Sim | Deleta o request upstream quando o provedor suporta deleção. Remoto ausente é sucesso. |
| `downloadDocuSealSignedDocument(options, id)` | Sim | Só funciona para submissões concluídas quando URLs de documento do provedor estão presentes; caso contrário falha como `signature-kit.UNSUPPORTED_OPERATION`. |

A criação é um único POST de submissão, então não há sequência de rollback multi-etapa para compensar após workflow parcial do provedor. Planos seguintes reutilizam o output em cache.

## Erros

Input inválido, falhas HTTP remotas e shapes de resposta inválidos falham como `SignatureKitError`. Os campos `provider`, `operation` e `status` HTTP são preservados quando a resposta upstream expõe esses dados.
