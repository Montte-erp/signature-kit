**What you'll do:** create a DocuSeal remote-signature request, keep credentials Redacted, and use only the lifecycle helpers exported by `@signature-kit/docuseal`.

DocuSeal creates a PDF submission and returns submitter links. It is a provider request API, not a local signer layer.

## Installation

```package-install
@signature-kit/http @signature-kit/docuseal
```

## When to use

Use DocuSeal when an open-source remote signer should host the submission and collect signatures. Use local signing when SignatureKit must produce the final bytes itself.

<Callout type="error" title="Keep credentials Redacted">
  Provider tokens enter as `Redacted.make(...)` and are unwrapped only inside the package HTTP boundary. Never pass remote tokens to React components or logs.
</Callout>

## Minimal request

```ts title="docuseal.ts"
import * as Alchemy from "alchemy"
import { DocuSealSignatureRequest, providers as docuSealProviders } from "@signature-kit/docuseal"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Effect, Layer, Redacted } from "effect"

export default class Contracts extends Alchemy.Stack<Contracts>()(
  "Contracts",
  {
    providers: docuSealProviders({
        apiKey: Redacted.make(process.env.DOCUSEAL_API_KEY ?? ""),
        submittersOrder: "preserved",
      }).pipe(
        // effect-boundary: Alchemy StackProps.providers closes provider and transport layers. [allow-provide]
        Layer.provide(signatureHttpClientLive),
        Layer.orDie,
      ),
    state: Alchemy.inMemoryState(),
  },
  Effect.gen(function* () {
    return yield* DocuSealSignatureRequest("contract", {
      title: "Service agreement",
      subject: "Please sign",
      message: "Please sign this agreement.",
      documents: [
        { fileName: "contract.pdf", mimeType: "application/pdf", contentBase64: pdfBase64 },
      ],
      recipients: [{ name: "Maria Souza", email: "maria@example.com", role: "signer" }],
      send: false,
    })
  }),
) {}
```

## Lifecycle

| Function | Supported | Notes |
| --- | --- | --- |
| `DocuSealSignatureRequest(id, props)` | Yes | Retained Alchemy resource. `reconcile` creates once and returns cached output on later plans. |
| `getDocuSealSignatureRequest(options, id)` | Yes | Reads the upstream request state. |
| `listDocuSealSignatureRequests(options)` | Yes | Package-level upstream list endpoint; Alchemy provider `list` returns `[]` and `nuke` is skipped. |
| Cancel helper | Not exported | This provider package does not expose a public cancel helper. Use delete only when the upstream supports removing the remote request. |
| `deleteDocuSealSignatureRequest(options, id)` | Yes | Deletes the upstream request when the provider supports deletion. A missing remote is success. |
| `downloadDocuSealSignedDocument(options, id)` | Yes | Only succeeds for completed submissions when provider document URLs are present; otherwise it fails as `signature-kit.UNSUPPORTED_OPERATION`. |

Create is a single submission POST, so there is no multi-step rollback sequence to compensate after a partial provider workflow. Subsequent plans reuse cached output.

## Errors

Invalid input, remote HTTP failures, and invalid response shapes fail as `SignatureKitError`. The `provider`, `operation`, and HTTP `status` fields are preserved when the upstream response exposes them.
