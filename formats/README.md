# formats/

Document-format packages. They mutate or inspect document bytes while consuming signer capabilities through `@signature-kit/signatures`.

## Packages

- [`formats/pdf`](pdf/README.md) → `@signature-kit/pdf` — PDF/PAdES signing, verification, visible stamps, anchors, rubrics, merge helpers, and browser text extraction.
- [`formats/xml`](xml/README.md) → `@signature-kit/xml` — XML-DSig signing and verification through an explicit `XmlRuntime`.
- [`formats/react`](react/README.md) → `@signature-kit/react` — headless React hooks for browser A1 signing and PDF object URLs.

Docs: <https://signaturekit.dev/en-US/docs/concepts/document-formats>.
